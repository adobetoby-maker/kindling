## 1. Unscored reader response

**Where interest caught.** Interest caught on the first line: a girl counting three hundred and forty paces because she said the number aloud. It caught again when a four-year-old looked at Meridian's single gate lamp and said "That's one" (`chapter-01.md:93`). From there, the movement kept finding hooks in small institutional objects that carry large feeling:

- "Persons in party." — "Two." (`01:481`)
- The back of Jab's card: "It does not touch his leg." (`02:37`)
- Four counted chairs, then five.
- Senna answering "Yes" before the question finished weighing (`03:115`).
- Tilda refusing Callie "the last sum" (`04:329`).
- Jab's "different heap" (`05:437`).
- Katori saying one word: "Vera."
- Callie choosing not to count the third breath (`07:119`).
- The machine's knocking dropping to "That's ten" (`08:213`).

The best of these are procedures that become moral events.

**Where it slipped.**

1. The first half of Chapter 4 waits at the scan door. Dessa's sensing explains itself twice there (`04:~149–189`, and again in Chapter 5).
2. The man in the long coat explains the Sag on a doorstep (`05:203–217`). It is clean and true, but it is the one passage that reads as briefing.
3. Chapter 6 opens back on day D+2 (`06:3`) after Chapter 5 has already reached D+5 (`05:395`, `05:451`: "Callie's mother had gone home two days ago"). For a page I thought I had missed a chapter.

**Which person matters.** Jab matters most on this read. Tonk is the movement's engine of warmth and dread. Callie has the strongest single scene: she does not count her mother's breathing. Toren is well written, but he mostly watches other people's events: Senna's diagnosis, Rook's announcement, Katori and Rook. He owns fewer choices than the other two.

**What I expect next.** I expect the calibration train to get worse before the joint Director's summons on D+13. Behind that, I expect Jab's answer on the four-season guard contract, and Katori eventually telling Rook why her people gave the stone and the state the same word.

**Would I continue?** Yes, without hesitation.

## Appendix A — Method (verbatim script)

- Run with: `python3 m001_metrics.py /Users/drive/kindling-repo-stage`
- Python 3.14.6, standard library only. `textstat`, `pyphen` and `nltk` are not installed; the syllable estimator below is self-contained.
- Script SHA-256 at the time of this run: `c05b04570a208e0b838e1b56028f65391550dce1fe43817be72e7f1990d28d4c`

**Definitions**

- **Word:** `[A-Za-z0-9]+` with internal apostrophes and hyphens kept, so "didn't" and "forty-one" each count as one word.
- **Paragraph:** a blank-line block, excluding the chapter heading and `---`. Markdown `*` is stripped.
- **Sentence:**
  - A paragraph end always ends a sentence.
  - Inside a paragraph, a sentence ends after `. ! ? … —` plus any closing quotes, when followed by whitespace and then an opening quote, capital or digit.
  - A lower-case continuation (`"…?" he said`) does not split.
- **Syllables:** vowel-group count, adjusted for silent -e, -es and -ed, with a small diphthong correction. It was checked against a 65-word hand-labelled gold list drawn from the manuscript.
- **Progression lexicon:** built for this project, restricted by context, with every match printed for audit. Excluded by construction:
  - the hospital "ward";
  - literal doors and edges;
  - the hut being "empty";
  - "two doors down";
  - non-ash "lifted it".
- **Development proxy:** a named character within 120 characters of a marker in the explicit list (`realised/realized, decided, for the first time, swore, no longer, understood, made up his/her mind, promised, learned, knew now, found he/she had`). This instantiates the formula's "etc."

Usage: python3 m001_metrics.py <repo_root>
Reads the eight chapters from the compiled review prompt, checks them against
books/book-02-meridian/manuscript/chapter-0N.md, and prints every metric used in
MOVEMENT-001-EDITORIAL-REVIEW.md.
"""

ROOT = pathlib.Path(sys.argv[1] if len(sys.argv) > 1 else ".")

    body = m.group(2).strip()
    body = re.sub(r"\n---\s*$", "", body).strip()      # compiler's trailing separator
    chapters[int(m.group(1))] = body
assert sorted(chapters) == list(range(1, 9)), chapters.keys()

def norm(s):
    return re.sub(r"\s+", " ", s).strip()

print("== coverage / identity ==")
for n, body in chapters.items():
    disk = (MS / f"chapter-0{n}.md").read_text().strip()
    disk = re.sub(r"\n---\s*$", "", disk).strip()

# ---------- tokenisation ----------
WORD = re.compile(r"[A-Za-z0-9]+(?:['’][A-Za-z]+)*(?:-[A-Za-z0-9]+(?:['’][A-Za-z]+)*)*")

def paragraphs(body):
    """Prose paragraphs: blank-line blocks, excluding the '# Chapter' heading and '---' breaks."""
    out = []
    for block in re.split(r"\n\s*\n", body):
        b = block.strip()
        if not b or b == "---" or b.startswith("# "):
            continue
        out.append(b.replace("*", ""))   # strip markdown italics
    return out

def sections(body):
    """Typographic sections: chapter text split on '---' lines."""
    parts = re.split(r"^\s*---\s*$", body, flags=re.M)
    return [p for p in parts if WORD.search(re.sub(r"^# .*$", "", p, flags=re.M))]

# Sentence split: paragraph end is always a sentence end; inside a paragraph, split after
# . ! ? or a closing em-dash, plus any closing quotes/brackets, when followed by whitespace and
# an opening quote or an uppercase letter/digit. Lower-case continuations ("...?" he said) do not split.
SPLIT = re.compile(r"(?<=[.!?…—])[\"'”’)\]]*\s+(?=[\"“'‘(]?[A-Z0-9])")
def sentences(par):
    return [s for s in SPLIT.split(par) if WORD.search(s)]

def words(s):
    return WORD.findall(s)

# ---------- syllables (heuristic, documented) ----------
def syllables(w):
    w = w.lower().replace("’", "'")
    w = re.sub(r"'(s|d|ll|re|ve|t|m)$", "", w)
    if re.fullmatch(r"\d+", w):
        return max(1, len(w))            # digits rare in this text
    parts = w.split("-")
    return sum(_syl(p) for p in parts if p)

def _syl(w):
    w = re.sub(r"[^a-z]", "", w)
    if not w:
        return 0
    if len(w) <= 3:
        return 1
    # silent endings: -e (not consonant+le), -es (not after s/x/z/ch/sh/c/g), -ed (not after t/d)
    if re.search(r"[^aeiouy]le$", w):
        pass
    elif re.search(r"(?:[sxz]|ch|sh|[cg])es$", w):
        pass
    elif re.search(r"[^aeiouy]es$", w):
        w = w[:-2]
    elif re.search(r"[td]ed$", w) or re.search(r"[^aeiouy]led$", w):
        pass
    elif re.search(r"[^aeiouy]ed$", w):
        w = w[:-2]
    elif re.search(r"[^aeiouy]e$", w) and not re.search(r"[aeiouy][^aeiouy]*e$", w) is None:
        w = w[:-1]
    w = re.sub(r"^y", "", w)
    n = len(re.findall(r"[aeiouy]+", w))
    # common diphthong splits that the vowel-group rule under-counts
    n += len(re.findall(r"(?:ia|io(?!u)|eo|ua|uo|iu)", w)) - len(re.findall(r"(?:tion|sion|cious|tious|cial|tial|geo|quo|qua|gua|gui)", w))
    return max(1, n)
