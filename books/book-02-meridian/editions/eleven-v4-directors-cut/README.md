# Meridian — Eleven v4 Director's Cut

This is the complete, upload-ready long-form narration manuscript for all 48 canonical chapters of *Meridian* by Monroe Jackson.

## Use

- Upload `Meridian-Eleven-v4-Directors-Cut.epub` as one complete book in ElevenLabs Audio Editor / Studio.
- Select Eleven v4 (`eleven_v4`).
- Choose the intended production voice, then set Stability and Similarity by ear for that voice.
- Treat bracketed lines as Eleven v4 inline audio direction tags.

The plain-text file contains the same full-book markup for review or fallback import. Individual chapter text files are included for targeted pickups.

## Editorial contract

- Canonical prose is word-locked to `manuscript/chapter-01.md` through `chapter-48.md`.
- Direction is placed at chapter openings and written scene breaks, not on every paragraph.
- No SSML is present. Eleven v4 does not use SSML pause markup.
- Markdown emphasis markers are removed because spoken emphasis is carried by the prose and v4 direction.
- Chapters 21, 29, 33, and 40 receive extra pacing direction for dense names, numbers, and ledger information; no prose is cut or rewritten.
- `manifest.json` binds every source chapter and directed chapter to SHA-256 hashes and records the successful word-lock check.

This edition is a narration-production artifact. It does not alter the canonical manuscript and it does not replace the separate Monroe Book Narrator / Original Calder production.
